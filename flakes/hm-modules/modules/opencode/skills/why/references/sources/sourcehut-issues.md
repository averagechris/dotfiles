# SourceHut issues

Use the `srht-issues` skill for todo.sr.ht when available. This dotfiles repository uses SourceHut as its authoritative tracker under `repo:dotfiles`. Do not assume another repository uses it. Confirm the tracker first.

Search ticket titles, bodies, comments, labels, related tickets, and links from commits. A ticket that states the reason can be Direct evidence. Record the ticket ID, status, author, dates, exact quote, and URL.

Keep searches bounded by repository, label, ticket ID, commit, and time range. Record access and indexing limits. Redact tokens, private URLs, and sensitive content as `[REDACTED]`.
