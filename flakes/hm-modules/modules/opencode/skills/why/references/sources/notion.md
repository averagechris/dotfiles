# Historical Notion documents

Notion mainly contains old RFCs and PRDs in this setup. Search repository Markdown first for current decisions and specs. Search Linear for current product and project context. Also use Notion when the user names or links a page, regardless of its age or type.

## Search

Use the available Notion skill, CLI, or integration. If the user points to Notion, inspect that page or search scope directly. Read the tool's instructions or help rather than assuming a schema.

1. Search feature names, symbols, dates, and known RFC or PRD titles.
2. Read full pages rather than previews.
3. Follow child pages and backlinks for alternatives or implementation notes.
4. Record page status, author, and dates. Prefer material from the target's era.

## Strong evidence

Look for a specific problem statement, alternatives considered, or an RFC that states a decision and reason.

## Failure modes

Plans often diverge from implementation. Show that contradiction instead of treating the document as authoritative. Reject boilerplate rationale. Compare multiple drafts and identify the final version. Record restricted pages as gaps. Never present an old page as current without corroboration.

## Return

For each document, provide title, URL, author, update date, status, section, exact motivation text, and relevant linked pages.
