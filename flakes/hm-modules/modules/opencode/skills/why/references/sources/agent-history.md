# Agent history leads

Use `ctx` only as a cross-cutting lead source. Try normal repository, document, tracker, and forge searches first. Use agent history to recover a missing link or prior search trail.

Prior sessions may point to commits, PRs, tickets, documents, meeting notes, or telemetry. Agent conclusions are not authoritative. Verify every claim against the cited code, PR, ticket, document, meeting note, or telemetry record before using it.

Keep searches bounded by project, symbol, path, issue ID, and date when supported. Record the query, session and event IDs, index scope, and relevant excerpt. State whether indexing covered the repository, host, tool, and time period. A null search is limited by what `ctx` indexed and retained, so it does not prove that no prior session exists.

Do not quote secrets, credentials, personal data, or sensitive payloads. Redact them as `[REDACTED]`. Return recovered links under the matching evidence category, not as independent proof.
