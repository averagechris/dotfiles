# Repository Markdown

Repository Markdown is the primary current long-form source. Search targeted paths for `README`, `docs/`, ADRs, RFCs, design notes, decision records, and `AGENTS.md` guidance. Start with names, symbols, ticket IDs, error text, and terms from the code anchor. Avoid an unbounded scan when a likely document set exists.

Read the relevant section and its surrounding context. Use VCS history and line attribution to learn when and why the text changed. Follow links to tickets, PRs, commits, and related documents.

Check status, date, author, and whether the described work shipped. Compare plans with the current code and call out stale guidance, abandoned proposals, and implementation drift. A current decision record that states a reason can be Direct evidence. A design draft or `AGENTS.md` rule may explain constraints but does not prove that one implementation followed it.

Return the repository-relative path, exact line range, heading, revision or commit when relevant, author and date when available, a short quote, and linked record IDs or URLs. Cite history claims with the revision that introduced or changed the text.
